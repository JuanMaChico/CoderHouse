# React.js - Clases y Ejemplos

![React](https://upload.wikimedia.org/wikipedia/commons/a/a7/React-icon.svg)

Este repositorio contiene una recopilación de clases y ejemplos prácticos para aprender y profundizar en el desarrollo con **React.js**.

## 📌 Contenido

- Introducción a React.js
- Componentes y Props
- Estado y Ciclo de Vida
- Manejo de Eventos
- Hooks en React
- React Router
- Gestión de Estado con Context API y Redux
- Integración con APIs
- Optimización y Buenas Prácticas

## 🚀 Requisitos

Antes de comenzar, asegúrate de tener instalado:

- [Node.js](https://nodejs.org/) (versión recomendada: LTS)
- [npm](https://www.npmjs.com/) o [yarn](https://yarnpkg.com/)
- Un editor de código (Recomendado: [VS Code](https://code.visualstudio.com/))

## 📂 Instalación

Puedes clonar este repositorio en tu máquina para tener este material de pruebas:

```bash
git clone https://github.com/JuanMaChico/CoderHouse.git
cd CoderHouse
npm install  # o yarn install
```

## ▶️ Uso

Para ejecutar los ejemplos en desarrollo:

```bash
npm start  # o yarn start
```

Esto iniciará la aplicación en modo de desarrollo y podrás acceder en [http://localhost:3000](http://localhost:3000).
